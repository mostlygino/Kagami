Kagami is installed

Open it from Applications or Spotlight.

First steps

  • Pick an interface and press ⌘R to record, or drop a capture or flow file on the window.
  • ⌘K finds any action, packet, host or filter.
  • Kagami > Check for Updates keeps it current.

From Terminal

If you linked the command line tool:

kagami packets capture.pcapng --filter tls --limit 5 --pretty

For Claude Code and other MCP clients:

claude mcp add kagami -- /usr/local/bin/kagami mcp
